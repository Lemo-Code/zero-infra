# base_interfaces_demo：接口模块详解

> 三个通信 demo 的**公共接口包**。  
> Topic / Service / Action 的调用过程文档、API 文档都依赖本包生成的类型。

---

## 1. 包职责

| 项 | 内容 |
|----|------|
| 包名 | `base_interfaces_demo` |
| 类型 | 纯接口包（几乎无运行节点） |
| 作用 | 用 `.msg` / `.srv` / `.action` 定义通信数据结构，构建时生成 C++/Python 等绑定 |

被依赖关系：

```text
base_interfaces_demo
    ↑
    ├── cpp01_topic      (Student.msg)
    ├── cpp02_service    (AddInts.srv)
    └── cpp03_action     (Progress.action)
```

---

## 2. 接口文件一览

| 文件 | 用于 | 通信模式 |
|------|------|----------|
| `msg/Student.msg` | 学生信息 | Topic |
| `srv/AddInts.srv` | 两数相加 | Service |
| `action/Progress.action` | 累加进度 | Action |

### 2.1 Student.msg

```text
string name
int32 age
float64 height
```

生成头文件：`base_interfaces_demo/msg/student.hpp`  
类型：`base_interfaces_demo::msg::Student`

### 2.2 AddInts.srv

```text
int32 num1
int32 num2
---
int32 sum
```

生成：`base_interfaces_demo/srv/add_ints.hpp`  
类型：`base_interfaces_demo::srv::AddInts`  
嵌套：`AddInts::Request` / `AddInts::Response`

### 2.3 Progress.action

```text
int32 num
---
int32 sum
---
float64 progress
```

生成：`base_interfaces_demo/action/progress.hpp`  
类型：`base_interfaces_demo::action::Progress`  
嵌套：`Progress::Goal` / `Result` / `Feedback`

## 3. 构建相关 API / CMake

`CMakeLists.txt` 核心：

```cmake
find_package(rosidl_default_generators REQUIRED)

rosidl_generate_interfaces(${PROJECT_NAME}
  "msg/Student.msg"
  "srv/AddInts.srv"
  "action/Progress.action"
)
```

| 模块/工具 | 作用 |
|-----------|------|
| `rosidl_default_generators` | 根据接口文件生成代码 |
| `rosidl_generate_interfaces` | CMake 宏：注册要生成的接口 |
| `rosidl_default_runtime` | 运行时类型支持（export） |
| `action_msgs` | Action 接口依赖的标准消息（`package.xml` 中 `depend`） |

`package.xml` 关键标记：

```xml
<member_of_group>rosidl_interface_packages</member_of_group>
```

表示这是接口包，供其它包 `find_package` / `depend`。

## 4. 命名规则（写 `#include` 时必会）

| 接口文件 | include | C++ 类型 |
|----------|---------|----------|
| `Student.msg` | `base_interfaces_demo/msg/student.hpp` | `...::msg::Student` |
| `AddInts.srv` | `base_interfaces_demo/srv/add_ints.hpp` | `...::srv::AddInts` |
| `Progress.action` | `base_interfaces_demo/action/progress.hpp` | `...::action::Progress` |

规则：包名 / `msg|srv|action` / **小写文件名** `.hpp`。

---

## 5. 修改接口后怎么做

1. 改 `.msg` / `.srv` / `.action`
2. 重新编译接口包及依赖它的包：

```bash
cd ~/learning/ws01_plumbing
colcon build --packages-select base_interfaces_demo cpp01_topic cpp02_service cpp03_action --symlink-install
source install/setup.bash
```

3. 若字段名/类型变了，同步改三个 demo 里的赋值与打印代码
